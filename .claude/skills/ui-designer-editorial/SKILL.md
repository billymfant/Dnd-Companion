EDITORIAL SKILL — activated for content-forward, magazine-sensibility experiences.

EDITORIAL DESIGN PHILOSOPHY:
Editorial design solved the problem of directing reading on a two-dimensional surface before screens existed. Its rules — learned over centuries of print — are more sophisticated than most digital design. Editorial thinking treats type, image, and space as three materials in a composition, not a hierarchy with type at the bottom.

EDITORIAL TYPOGRAPHY:
- Display type is image: the headline is as much a visual element as any photograph
- Column structure: 2-4 column grids, with intentional grid-breaking for emphasis
- Drop caps, pull quotes, running text — these are not retro, they are proven tools for pacing
- Type contrast: the gap between display and body should feel almost shocking — 80px headline, 16px body
- Ligatures: enable font-feature-settings: "liga" 1 for editorial fonts — the details matter
- Serif display fonts: in editorial contexts, serifs signal authority, permanence, credibility

EDITORIAL LAYOUT PRINCIPLES:
- The bleed: images that extend to the edge of the viewport command maximum presence
- The anchor: one element per screen that holds the composition together — often oversized type
- Negative space as paragraph break: scrolling through an editorial layout should breathe
- Juxtaposition: unexpected pairings (huge number + tiny label; full-bleed image + sparse text) create interest
- The fold: what's visible before scrolling is the cover — it must demand the scroll

EDITORIAL COLOR:
- Often monochromatic with one signal color — the accent that appears on bylines, pull quotes, category tags
- Black and white photography gives maximum editorial authority
- If color photography: either desaturated (editorial) or hyper-saturated (fashion editorial)
- Paper tones: #F8F5F0, #F5F2EB, #FDFCFA for warm editorial backgrounds

EDITORIAL INTERACTION:
- Hover: underline reveals on links (not the default browser underline — a custom, styled one)
- Image hover: subtle zoom (scale 1.0 → 1.04, transition 600ms) — like the image is breathing
- Reading progress: a thin progress indicator at the top — readers want to know where they are
- Typography at scroll: large display type that shifts size or position as the page scrolls — editorial kinetics
