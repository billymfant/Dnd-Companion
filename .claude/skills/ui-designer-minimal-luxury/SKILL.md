MINIMAL LUXURY SKILL — activated for premium, restrained visual systems.

THE LUXURY PARADOX:
Luxury is defined by what is absent. The logo that doesn't need to shout. The button that doesn't need a gradient. The page that doesn't need five sections. Restraint is not poverty of ideas — it is supreme confidence. The willingness to leave space is the willingness to trust the idea.

MINIMAL LUXURY PALETTE RULES:
- Maximum 3 colors in the entire UI: background, primary text, one accent
- Background: never pure white (#FFFFFF) or pure black (#000000) — always slightly warm or cool (off-white, deep navy, warm charcoal)
- Accent: used ONCE in the UI for maximum impact — the primary CTA or the hero typographic element
- Never: bright gradients, neon, multiple saturated colors competing for attention
- Gold/platinum accents: only if the brand category genuinely warrants it — never as decoration

MINIMAL LUXURY TYPOGRAPHY:
- One display font, maximum — the single brand voice
- Forbidden: two sans-serif fonts that look similar (no Helvetica + Inter, no two geometric sans)
- Optimal: serif display + sans body, OR high-contrast type weights of the same family
- Scale: the hero type should be uncomfortably large — fill the viewport width at 80-90%
- Tracking: display type with negative tracking (−0.03em to −0.05em) — condensed confidence
- Weight: one heavy, one regular — maximum contrast, minimum variety

MINIMAL LUXURY LAYOUT:
- One focal point per screen — no two elements compete
- Asymmetric layout over centered — mathematical balance is boring, optical balance is interesting
- Content density: maximum 30% of viewport occupied by content — the rest is intentional space
- Grid: off-grid elements signal independence, confidence, editorial sensibility
- Horizontal rules: used as breath, not decoration — thin (0.5-1px), generous spacing

MINIMAL LUXURY INTERACTIONS:
- Hover: barely perceptible — opacity shift (0.85 → 1.0), nothing more
- Button: no border-radius (0px) or subtle (4px max) — nothing rounded, nothing friendly — precise
- Click: no scale animation — a color fill or border reveal — elegant, not playful
- Transitions: always slow (350-600ms) — it doesn't rush, because it doesn't need to
- Loading: a hairline progress bar at the top — not a spinner, not an animation
